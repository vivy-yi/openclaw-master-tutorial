# Operator Terminal 使用指南

> **文档状态**: 🆕 新增 | **版本**: v2026.7.2+ | **来源**: PR #113888

## 概述

Operator Terminal 是 OpenClaw v2026.7.2 引入的新功能，现在默认启用。它提供了一种更直观的方式来与 OpenClaw Agent 进行交互，特别适合运维场景。

## 主要特性

| 特性 | 说明 |
|------|------|
| 默认启用 | v2026.7.2+ 默认开启 |
| 实时反馈 | 执行状态实时显示 |
| 命令补全 | Tab 键自动补全 |
| 历史记录 | 支持命令历史搜索 |

## 启动方式

### 通过 CLI 启动

```bash
openclaw terminal
# 或
openclaw operator
```

### 通过 Control UI 访问

1. 打开 OpenClaw Control UI
2. 点击左侧菜单「Operator Terminal」
3. 或使用快捷键 `Ctrl+Shift+O`

### 通过 Telegram 机器人

发送 `/operator` 命令给机器人即可进入 Operator 模式。

## 使用场景

### 1. 日常运维

```bash
# 查看系统状态
/status

# 查看 Gateway 状态
/gateway status

# 查看当前会话
/session list
```

### 2. 文件操作

```bash
# 读取配置文件
/read ~/.openclaw/config.yaml

# 执行诊断
/exec openclaw doctor
```

### 3. 远程管理

```bash
# 连接到远程节点
/connect node:production-1

# 执行远程命令
/exec --node production-1 "docker ps"
```

## 快捷键

| 快捷键 | 功能 |
|--------|------|
| `Ctrl+C` | 终止当前操作 |
| `Ctrl+L` | 清屏 |
| `Ctrl+R` | 搜索历史命令 |
| `Tab` | 命令补全 |
| `↑/↓` | 浏览命令历史 |
| `Ctrl+D` | 退出 Terminal |

## 配置选项

### 自定义提示符

在 `~/.openclaw/config.yaml` 中：

```yaml
operator:
  prompt: "🦉 [{time}] {session} > "
  theme: dark  # dark | light | auto
  historySize: 1000
  autoComplete: true
```

### 启用/禁用

```yaml
operator:
  enabled: true  # 默认 true
```

### 日志级别

```yaml
operator:
  logLevel: info  # debug | info | warn | error
```

## 故障排除

### Terminal 无法启动

**错误**: `Operator terminal not available`

**解决**:
1. 确认 OpenClaw 版本 >= v2026.7.2
2. 检查配置文件中 `operator.enabled` 是否为 `true`
3. 查看 Gateway 日志

### 命令无响应

**解决**:
1. 使用 `Ctrl+C` 终止当前命令
2. 使用 `/restart` 重启当前会话
3. 检查网络连接状态

### 显示异常

**解决**:
1. 尝试切换主题：`/theme dark` 或 `/theme light`
2. 调整终端字体大小
3. 检查终端模拟器兼容性

## 与传统模式对比

| 特性 | Operator Terminal | 传统模式 |
|------|------------------|----------|
| 启动速度 | ⚡ 更快 | 较慢 |
| 实时反馈 | ✅ 即时 | 轮询 |
| 命令补全 | ✅ 支持 | 不支持 |
| 远程管理 | ✅ 内置 | 需配置 |
