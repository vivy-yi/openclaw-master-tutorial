# Kimi K3 模型配置指南

> **文档状态**: 🆕 新增 | **版本**: v2026.7.2+ | **来源**: PR #113909

## 概述

Kimi K3 是月之暗面（Moonshot AI）推出的国产大语言模型，已被添加为 OpenClaw 的一级支持模型。本指南介绍如何在 OpenClaw 中配置和使用 Kimi K3。

## 支持的功能

| 功能 | 支持状态 | 说明 |
|------|----------|------|
| 对话补全 | ✅ 支持 | 基础对话能力 |
| 函数调用 | ✅ 支持 | Tool calling |
| 流式输出 | ✅ 支持 | Streaming responses |
| Token 上下文 | ✅ 支持 | 128K 上下文窗口 |
| Vision | ✅ 支持 | 多模态图像理解 |

## 配置步骤

### 1. 获取 API Key

1. 访问 [月之暗面开放平台](https://platform.moonshot.cn/)
2. 注册/登录账号
3. 在「API 密钥」页面创建新的 API Key
4. 复制并妥善保存 API Key

### 2. 配置 OpenClaw

在 `~/.openclaw/config.yaml` 中添加：

```yaml
models:
  providers:
    - id: kimi-k3
      type: openai-compatible
      apiBaseUrl: https://api.moonshot.cn/v1
      apiKey: ${KIMI_API_KEY}  # 推荐使用环境变量
      defaultModel: kimi-k3-0711-preview
      capabilities:
        - chat-completion
        - tools
        - vision

# 环境变量配置
env:
  KIMI_API_KEY: "your-kimi-api-key-here"
```

### 3. 模型选择

在对话中切换模型：

```
/model kimi-k3
```

或通过 Control UI 的模型选择器选择 Kimi K3。

### 工具配置

Kimi K3 支持完整的工具调用能力。建议配置常用工具：

```yaml
tools:
  enabled:
    - browser
    - exec
    - read
    - write
    - web-search
```

### 成本控制

Kimi K3 的定价策略：
- 输入: ¥10/1M tokens
- 输出: ¥10/1M tokens

建议设置使用限额：

```yaml
models:
  budget:
    daily: 100  # 每日限额（人民币）
```

## 故障排除

### API Key 无效

**错误**: `Authentication failed`

**解决**:
1. 确认 API Key 正确
2. 检查 API Key 是否已过期
3. 确认账户有足够余额

### 网络连接问题

**错误**: `Connection timeout`

**解决**:
1. 确认网络可以访问 `api.moonshot.cn`
2. 检查防火墙/代理设置
3. 尝试使用代理或 VPN

### 模型响应慢

**解决**:
1. 尝试使用 `kimi-k3-flash` 版本
2. 减少上下文长度
3. 检查网络延迟
