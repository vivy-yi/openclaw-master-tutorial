# 1Password SecretRef 集成指南

> **文档状态**: 🆕 新增 | **版本**: v2026.7.2+ | **来源**: PR #113681 ~ #113728

## 概述

1Password SecretRef 是 OpenClaw v2026.7.2 引入的企业级密钥管理集成。通过 SecretRef 机制，您可以安全地引用 1Password 中存储的密钥和敏感信息，无需在配置文件中明文暴露。

## 特性

| 特性 | 说明 |
|------|------|
| 密钥引用 | 使用 SecretRef 引用 1Password 中的密钥 |
| 自动刷新 | 密钥变更时自动更新 |
| 审计日志 | 记录所有密钥访问 |
| 零信任 | 不存储实际密钥值 |

## 前置要求

### 1. 安装 1Password CLI

```bash
# macOS
brew install 1password-cli

# Linux
sudo apt-get install 1password-cli

# 验证安装
op --version
```

### 2. 配置 1Password 集成

```bash
# 登录 1Password
op signin

# 验证连接
op vault list
```

## 配置步骤

### 1. 配置 OpenClaw

在 `~/.openclaw/config.yaml` 中：

```yaml
secrets:
  provider: 1password
  vault: "OpenClaw"  # 1Password Vault 名称
  
# 使用 SecretRef 引用密钥
models:
  providers:
    - id: openai
      apiKey: ${op://OpenClaw/api-key}  # SecretRef 语法
```

### 2. SecretRef 语法

```
op://{vault}/{item-name}/{field}
```

| 部分 | 说明 | 示例 |
|------|------|------|
| vault | Vault 名称 | OpenClaw |
| item-name | 条目名称 | GitHub Token |
| field | 字段名 | password, username, notes |

### 3. 完整配置示例

```yaml
secrets:
  provider: 1password
  vault: "OpenClaw"
  cacheTtl: 300  # 缓存时间（秒）

models:
  providers:
    - id: openai
      apiKey: ${op://OpenClaw/openai-api-key/password}
      
env:
  # 环境变量引用
  GITHUB_TOKEN: ${op://OpenClaw/github-token/password}
  AWS_ACCESS_KEY_ID: ${op://OpenClaw/aws-access-key/username}
  AWS_SECRET_ACCESS_KEY: ${op://OpenClaw/aws-secret-key/password}

plugins:
  installs:
    - name: github
      config:
        token: ${op://OpenClaw/github-plugin-token/password}
```

## 在 1Password 中创建条目

### 方式一：命令行

```bash
# 创建新条目
op item create \
  --vault "OpenClaw" \
  --category "Login" \
  --title "OpenAI API Key" \
  --username "user@example.com" \
  --password "sk-xxx" \
  --url "https://api.openai.com"
```

### 方式二：1Password App

1. 打开 1Password 应用
2. 选择 "OpenClaw" Vault
3. 点击「新建项目」→「登录」
4. 填写标题和密码字段

### 推荐条目结构

```
Vault: OpenClaw
├── openai-api-key (Login)
│   ├── username: user@example.com
│   ├── password: sk-xxx
│   └── url: https://api.openai.com
├── github-token (Secure Note)
│   └── notes: ghp_xxx
├── aws-credentials (Identity)
│   ├── username: AKIAIOSFODNN7EXAMPLE
│   └── password: wJalrXUtnFEMI/K7MDENG/bPxRfiCYEXAMPLEKEY
└── database-credentials (Login)
    ├── username: db_user
    ├── password: secure_password
    └── url: postgresql://localhost:5432/db
```

## 最佳实践

### 1. 分离不同环境的密钥

```yaml
# 生产环境
models:
  providers:
    - id: openai-prod
      apiKey: ${op://Production/openai-api-key/password}

# 开发环境
models:
  providers:
    - id: openai-dev
      apiKey: ${op://Development/openai-api-key/password}
```

### 2. 定期轮换密钥

```bash
# 轮换 API Key
op item edit "OpenClaw/openai-api-key" \
  --password "new-api-key-value"
  
# OpenClaw 将自动检测并更新
```

### 3. 使用访问组

```yaml
secrets:
  provider: 1password
  vault: "OpenClaw"
  accessGroup: "openclaw-service-account"
```

## 故障排除

### 认证失败

**错误**: `Failed to authenticate with 1Password`

**解决**:
1. 确认已执行 `op signin`
2. 检查 `OP_SESSION` 环境变量
3. 重新登录：`op signin`

### 找不到条目

**错误**: `Item not found: {item-name}`

**解决**:
1. 确认 Vault 名称正确
2. 确认条目名称正确
3. 验证访问权限：`op item get {item-name} --vault {vault}`

### 权限不足

**错误**: `Insufficient permissions`

**解决**:
1. 确认 1Password 账户有访问该 Vault 的权限
2. 联系 Vault 管理员请求访问权限

### 缓存问题

**解决**:
```yaml
secrets:
  cacheTtl: 0  # 禁用缓存
```

## 与 Vault 集成

1Password SecretRef 可以与 OpenClaw Vault 结合使用：

```yaml
vault:
  provider: 1password
  encryptionKey: ${op://OpenClaw/vault-encryption-key/password}
```
