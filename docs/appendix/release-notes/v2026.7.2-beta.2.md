## 二、v2026.7.2-beta.2 Highlights（主要更新）

### 2.1 远程编码会话 ⭐ 新功能

**核心改进**：在云工作器上运行 Control UI 会话，在终端打开 Codex/Claude 目录会话。

| 特性 | 说明 |
|------|------|
| 远程 Control UI | 云工作器运行会话 |
| 终端目录会话 | 本地终端打开 Codex/Claude |
| 混合部署 | 灵活选择运行位置 |

**使用场景**：
- 资源受限本地设备 → 远程会话
- 需要本地文件访问 → 终端会话
- 大型项目开发 → 混合模式

---

### 2.2 原生自动化与节点增强

**核心改进**：Android 语音唤醒、Linux 节点相机/位置/通知能力。

| 平台 | 新增能力 |
|------|----------|
| **Android** | 语音唤醒 |
| **Linux** | 相机控制 |
| **Linux** | 位置服务 |
| **Linux** | 通知管理 |

**优势**：
- 移动端交互更自然
- Linux 节点功能完整
- 跨平台自动化统一

---

### 2.3 更安全的频道操作

**核心改进**：Telegram 持久入口保护、Signal 停止/审批控制改进。

| 频道 | 改进点 |
|------|--------|
| **Telegram** | 持久入口保护 |
| **Signal** | 停止控制改进 |
| **Signal** | 审批流程优化 |

**安全增强**：
- 防止未授权访问
- 精细化权限控制
- 操作审计可追溯

---

### 2.4 引导式 Control UI 设置

**核心改进**：从设置配置模型提供商、引导式频道接入。

| 功能 | 说明 |
|------|------|
| 模型提供商配置 | 图形化配置界面 |
| 引导式频道接入 | 新手友好 |
| ClickClack 支持 | 更流畅的配置体验 |

---

### 2.5 Gateway 和会话恢复

**核心改进**：防止重启卡顿、回复会话恢复、单次 cron 作业生命周期。

| 改进点 | 说明 |
|--------|------|
| 重启保护 | 防止重启卡顿 |
| 会话恢复 | 回复会话恢复 |
| Cron 生命周期 | 单次作业完整管理 |

**关联修复**：
- #95866 Gateway 强制重启丢回复（部分修复）
- 心跳任务在调度运行期间保持活跃 (PR #110193)

---

### 2.6 安装与打包改进

**核心改进**：Linux deb/AppImage 包、Windows winget 安装后继续。

| 平台 | 改进 |
|------|------|
| **Linux** | deb 包支持 |
| **Linux** | AppImage 支持 |
| **Windows** | winget 安装后继续 |
