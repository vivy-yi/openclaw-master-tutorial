## 二、Highlights

> 以下为核心亮点功能，完整变更列表见第三章。

### 🆕 新增功能 (New)

- **Kimi K3 一级支持**: OpenClaw 新增对 Kimi K3 模型的原生一级支持，Kimi 成为重要模型提供商 (#113909)
- **Operator Terminal 默认启用**: Gateway Operator Terminal 功能默认启用，运维体验提升 (#113888)
- **Browser Action - 页面问答**: 新增 Browser Action，可以通过子模型调用回答页面问题，浏览器自动化增强 (#113861)
- **Session Rail + Control UI Chat**: 在 Control UI Chat 中引入 Session Rail 和只读 Session Companion (#113698)
- **Swarm 进度在 Chat 中显示**: 在 Chat 界面显示 Swarm 多智能体进度 (#113850)
- **1Password SecretRef 完整集成**: 完整的 1Password SecretRef 生产级集成，支持安全密钥管理 (#113681, #113691, #113704, #113705, #113728)
- **Vault 安全修复**: 修复 Vault 不安全 Secrets Plan 写入问题 (#113707)
- **ClickClack 命令菜单**: 发布每个 Bot 的原生 OpenClaw 命令到 ClickClack composer 自动补全 (#113674, #113727)

### 🚀 核心增强 (Core)

- **远程编码会话**: 在云工作线程上运行 Control UI 会话，在其所属主机终端打开 Codex 和 Claude catalog 会话，并支持直接在终端恢复 OpenCode 和 Pi 会话
- **原生自动化与节点**: 移动端自动化能力对齐，Android 前台语音唤醒，云端 Linux 节点相机、位置和通知能力暴露
- **更安全的渠道操作**: 防止 Telegram 持久入口重启后丢失，保持 Signal 停止和审批控制在活动轮次期间响应，阻止渠道白名单授予所有者访问权限
- **引导式 Control UI 配置**: 从 Settings 配置模型提供商，通过引导设置页面上渠道，选择镜像和模型同时创建会话

### 🔧 安装与打包

- **Linux 安装包**: 新增 Linux deb 和 AppImage 包，配合 Gateway 引导安装
- **Windows 安装优化**: Windows 安装可在 winget 添加 Node.js 后立即继续

### 🛡️ 安全与稳定性

- **外部 Gateway 监督**: 新增 `OPENCLAW_SUPERVISOR_MODE=external` 支持 OCM 等生命周期所有者
- **Gateway 和会话恢复**: 防止重启准入卡住 Gateway，恢复最终化停滞后的回复会话，保持一次性 cron 任务在生命周期声明竞争中保持启用
- **Vault 安全修复**: 修复 Vault 不安全 Secrets Plan 写入

## 六、升级指南

### 6.1 推荐升级方式

```bash
# 使用 npm 更新
npm update -g openclaw

# 或使用 Homebrew
brew upgrade openclaw

# 验证版本
openclaw --version
# 应显示 v2026.7.2
```

### 6.2 重大变更提醒

| 变更 | 影响 | 建议 |
|------|------|------|
| `OPENCLAW_SUPERVISOR_MODE=external` | OCM 用户新选项 | 查看外部监督文档 |
| 1Password SecretRef | 需要重新配置 | 参照 1Password 集成文档 |
| ClickClack 命令菜单 | 无需配置 | 自动启用 |
| Skill Workshop 自动审批 | 默认无需审批 | 如需审批可设置 `skills.workshop.approvalPolicy: "pending"` |

### 6.3 数据迁移

| 迁移项 | 是否需要 | 说明 |
|--------|---------|------|
| SQLite Schema | 可选 | `openclaw doctor --fix` 可检查 |
| 1Password 配置 | 需要 | SecretRef 配置需重新验证 |
| ClickClack 配置 | 无需 | 向后兼容 |
