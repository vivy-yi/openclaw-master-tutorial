## ✨ 亮点功能

### 1. Control UI 大改版

全新设计的 Control UI 带来更现代化的交互体验：

- **会话侧边栏**: 重新设计的侧边栏，分类清晰，切换流畅
- **Live Tasks**: 实时查看异步任务执行状态
- **清晰聊天控制**: 优化消息管理，支持置顶、标记、搜索

> 相关 PR: 2,018 个 commits，532 位贡献者

### 2. 官方 App 全面更新

iOS/iPadOS、Android、macOS 官方客户端全面升级：

| 平台 | 更新内容 |
|------|----------|
| iOS/iPadOS | 性能优化、通知增强、支持 iPad 多窗口 |
| Android | Material You 设计语言适配、后台稳定性提升 |
| macOS | Apple Silicon 优化、Control UI 原生集成 |

### 3. 新模型支持

- **GPT-5.6**: OpenAI 最新 GPT-5 系列模型
- **Tencent Hy3**: 腾讯混元大模型
- **Meta Muse Spark 1.1**: Meta 音乐生成模型

### 4. 渠道增强

各消息渠道均有重大更新：

| 渠道 | 更新内容 |
|------|----------|
| **Telegram** | 持久入口修复，支持会话续传 |
| **Slack** | 改进线程管理，支持更多交互组件 |
| **Discord** | Thread 集成增强，支持声浪播放 |
| **Apple Messages** | 改进 MMS 处理，照片质量优化 |

### 5. Gateway 稳定性提升

- **崩溃循环修复**: 有效防止 Gateway 重启后进入崩溃循环
- **定时工作稳定**: Cron 任务执行可靠性大幅提升
- **远程浏览器控制**: 远程 browser 调用稳定性改进
