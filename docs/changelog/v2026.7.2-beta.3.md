## ✨ 亮点功能

### 1. 远程编码会话 (Remote Coding Sessions)

在云端 Workers 上运行 Control UI 会话，在终端中打开 Codex 和 Claude 目录会话，并在其所属主机上恢复 OpenCode 和 Pi 会话。

- **相关 Issue**: #107670, #107086, #107200

### 2. 原生自动化与节点 (Native Automation & Nodes)

- 将 Automations 能力对齐到移动端
- 在 Android 上添加前台语音唤醒 (Voice Wake)
- 从无头 Linux 节点暴露相机、位置和通知能力

- **相关 Issue**: #106355, #107081, #107193

### 3. 更安全的渠道操作 (Safer Channel Operation)

- 防止 Telegram 持久入口在重启后丢失
- 在活跃回合中保持 Signal 停止和批准控制响应
- 阻止渠道白名单授予所有者权限

- **相关 Issue**: #107288, #107422, #107403
- **感谢贡献者**: @obviyus, @arduano, @yetval

### 4. 引导式 Control UI 设置

- 从设置中配置模型提供商
- 通过引导式设置页面 onboarding 渠道
- 创建会话时选择图像和模型

- **相关 Issue**: #106490, #106469, #107358
- **感谢贡献者**: @alexandre-leng, @fuller-stack-dev

### 5. Gateway 与会话恢复

- 防止重启准入卡住 Gateway
- 在最终化停滞后恢复回复会话
- 在生命周期声明竞态中保持一次性 cron 作业启用

- **相关 Issue**: #107339, #106792, #107236
- **感谢贡献者**: @obviyus, @joshavant, @charliemeyer2000, @SL4N

### 6. 安装与打包

- 添加 Linux deb 和 AppImage 包，带 Gateway 指导
- 从稳定的主分支发布
- 让 Windows 安装在 winget 添加 Node.js 后立即继续

- **相关 Issue**: #106533, #106891, #106862

## 📝 变更详情

### 外部 Gateway 监督

添加 `OPENCLAW_SUPERVISOR_MODE=external` 用于生命周期所有者（如 OCM），保留验证的重启和延迟行为，不暴露原生服务权限，阻止原生服务变更和自更新，并提供版本化的原子重启交接消费合约。

- **感谢**: @shakkakkernerd

### ClickClack 引导式设置

通过 `openclaw onboard` 或 `openclaw channels add clickclack` 配置 ClickClack，包含 URL、token 和 workspace 提示，默认账户环境回退，非致命实时连接验证，以及 Gateway 感知的下一步，当 OpenClaw 已运行时自动连接。

- **感谢**: @shakkakkernerd

### ClickClack 命令菜单

在 Gateway 启动时将每个机器人的原生 OpenClaw 命令发布到 ClickClack 作曲器自动完成，每个账户可选择退出，并对较旧的 token 和服务器进行非致命兼容性处理。

- **感谢**: @shakkakkernerd, @vincentkoc

### Skill Workshop 审批

默认运行代理发起的 apply、reject 和 quarantine 操作，无需额外审批提示，同时保留 `skills.workshop.approvalPolicy: "pending"` 作为可选审批门。

- **感谢**: @shakkakkernerd

### TUI 模糊选择器

将列表匹配委托给 pi-tui，添加斜杠-token 和字母数字匹配，同时移除本地匹配器分支。

### macOS 配对节点终端

从嵌入式节点主机宣传双向 Codex 和 Claude 终端恢复命令，并通过原生应用桥转发交互式输入和取消。

- **相关 Issue**: #107335

### Control UI 目录终端

在 Gateway 或配对节点主机上的原生 CLI 中打开符合条件的 Codex 和 Claude Code 会话，带有查看器与终端偏好设置、验证的恢复命令和交互式 PTY 中继。

- **相关 Issue**: #107086
- **感谢**: @vincentkoc

### Skill Workshop 历史审查

添加手动、最新优先的会话扫描，逐步搜索更早的重要工作以获取保守的技能创意，仅存储 SQLite 游标元数据，并在禁用自主自学习时保留最多三个待定提案。

- **相关 Issue**: #106182

### OpenAI GPT-5.6 默认值

为新的 API 密钥设置使用 `openai/gpt-5.6`（Sol 别名），为新的 Codex/OAuth 设置使用精确的 `openai/gpt-5.6-sol`，在两个运行时中将 Sol 默认为中等推理，并保留现有的主要、回退、别名和显式 GPT-5.5 选择。

- **相关 Issue**: #103234

### iOS 离线聊天

从受保护的、有限制的每个 Gateway 缓存中预绘制最近会话和规范转录，保持离线时发送禁用，并在重置配对时清除缓存的对话文本。

- **相关 Issue**: #100194

### Slack 进度指示器

默认使用 Slack 原生助手线程状态和轮播加载消息，同时保持确认反应静态；生命周期反应更新现在需要 `messages.statusReactions.enabled: true`。

### Control UI Talk 控制

将语音、模型、灵敏度和其他实时默认值保留在设置 → 通信 → Talk 中，并使用作曲器麦克风插入符选择任何浏览器音频输入。

- **相关 Issue**: #101046

### Control UI 会话工作区快捷键

使用 ⇧⌘B 展开或折叠活动聊天窗格的工作区轨道，而不更改主应用侧边栏或单独的详情和 Canvas 预览面板。

- **感谢**: @shakkakkernerd

### Control UI 设置快捷键

使用 ⇧⌘, 打开设置，同时保持浏览器拥有的 ⌘, 快捷键不变。

- **感谢**: @shakkakkernerd

## 🔄 迁移指南

### ClickClack 迁移

如果使用 ClickClack，运行以下命令进行迁移：

```bash
openclaw onboard
# 或
openclaw channels add clickclack
```

### Gateway 监督模式

如需使用外部监督模式，设置环境变量：

```bash
OPENCLAW_SUPERVISOR_MODE=external
```
